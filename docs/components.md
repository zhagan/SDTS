# Components

## Core

Maintains simulation state.

## Renderer

Displays targets.

Future implementations:

-   Browser
-   ILDA
-   LightElf
-   Ether Dream

## Impact Adapter

Converts device-specific data into protocol messages.

Future implementations:

-   Mouse
-   ShotMarker
-   FreeETarget

## Recorder

Stores every message for replay.
